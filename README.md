# fukumatch（フクマッチ）

> いらない服を、誰かのお気に入りに。

**fukumatch** は「服版Tinder」—— いらなくなった服をスワイプして、マッチングしたら実際に会って交換するサステナブルファッションプラットフォームです。

## 🌐 Website

GitHub Pages: [https://YOUR_USERNAME.github.io/fukumatch/](https://YOUR_USERNAME.github.io/fukumatch/)

## ✨ Features

- 📸 服を撮影してアップロード
- 👆 スワイプで気になる服を選ぶ
- 💕 お互いが気に入ったらマッチング成立
- 🤝 実際に会って服を交換

## 🚀 Deploy to GitHub Pages

1. GitHubで新しいリポジトリを作成（例: `fukumatch`）
2. 以下のコマンドでデプロイ:

```bash
git init
git add .
git commit -m "Initial commit - fukumatch landing page"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/fukumatch.git
git push -u origin main
```

3. GitHubリポジトリの **Settings** → **Pages** → Source: `main` branch, `/ (root)` を選択
4. 数分後にサイトが公開されます！
